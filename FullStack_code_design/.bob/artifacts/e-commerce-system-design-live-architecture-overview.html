ActionEndpointWhat Happens in Each ServiceDesign Pattern
Register POST /auth/register PostgreSQL: INSERT into users + user_roles
Redis: SET token:refresh:{userId} = refreshToken, TTL=7d
Response: accessToken (15min) + refreshToken (7d) 		FacadeStrategy (BCrypt)
Login POST /auth/login PostgreSQL: SELECT user by email (idx_users_email)
BCrypt: compare password hash (~100ms intentional)
Redis: SET token:refresh:{userId}, overwrites old one
Response: new accessToken + refreshToken 		RepositoryStrategy
API Request GET /auth/me (any protected route) JwtAuthFilter: extract Bearer token
JWT verify: signature + expiry (in-memory, ~1ms)
Redis: GET token:blacklist:{jti} — revocation check
PostgreSQL: SELECT user WHERE active=true
SecurityContext: set userId + roles 		Chain of Responsibility
Logout POST /auth/logout Redis: SET token:blacklist:{jti} = "revoked", TTL=remaining
Redis: DEL token:refresh:{userId}
Result: token rejected on next request 		Blacklist Pattern
Token Refresh POST /auth/refresh JWT verify: signature + expiry + type=refresh
Redis: GET token:refresh:{userId} → compare exact match
PostgreSQL: reload current roles
Response: new accessToken (15min) 		Silent Refresh

🔗 Frontend ↔ Backend Contract

Angular ComponentCallsNgRx FlowToken Handling
LoginComponent POST /auth/login dispatch loginRequest → Effect → loginSuccess → Reducer stores user+token accessToken → NgRx store; refreshToken → localStorage
authInterceptor Every HTTP request reads selectAccessToken from store → adds Authorization: Bearer … Runs before every outgoing request
errorInterceptor Every HTTP response catches 401 → dispatch logout → redirect to /auth/login Prevents stale token loops
authGuard Route activation reads selectIsLoggedIn from store → allow or redirect Protects /cart, /orders, /profile
roleGuard('ADMIN') Route activation reads selectHasRole('ADMIN') → allow or redirect to /403 Protects /admin routes
App bootstrap GET /auth/me dispatch restoreSession → Effect reads localStorage token → calls /auth/me → restores NgRx state No re-login needed after page refresh

🧪 How to Verify Each Service is Working Correctly

1. PostgreSQL — see your data

# Connect to DB
docker exec -it ecommerce-postgres psql -U ecommerce_user -d ecommerce

# List all users
SELECT id, name, email, is_active, created_at FROM user_domain.users;

# See roles assigned to each user
SELECT u.email, ur.role FROM user_domain.users u JOIN user_domain.user_roles ur ON u.id = ur.user_id;

# Check indexes created
\d user_domain.users

2. Redis — inspect tokens live

# Connect to Redis CLI
docker exec -it ecommerce-redis redis-cli

# List all keys
KEYS *

# See a refresh token value (copy a userId from PostgreSQL)
GET token:refresh:52e5ba53-18cb-42e8-b0e4-05860031180e

# Check TTL (how long until it expires)
TTL token:refresh:52e5ba53-18cb-42e8-b0e4-05860031180e

# After logout — see the blacklist entry appear
KEYS token:blacklist:*
TTL token:blacklist:<jti-value>

3. Kafka — browse messages visually

# Open Kafka UI in browser
http://localhost:8090

# Or list topics from CLI
docker exec ecommerce-kafka kafka-topics --bootstrap-server localhost:9092 --list

# Consume messages from a topic (once orders are placed)
docker exec ecommerce-kafka kafka-console-consumer \
  --bootstrap-server localhost:9092 \
  --topic order.placed --from-beginning

4. Elasticsearch — check cluster health

# Cluster health
curl http://localhost:9200/_cluster/health?pretty

# List indexes (will show products index once product module is added)
curl http://localhost:9200/_cat/indices?v

# Open Kibana for visual search
http://localhost:5601

5. Backend API — test with curl or Swagger

# Swagger UI (easiest — click & test)
http://localhost:8080/swagger-ui.html

# Health + metrics
curl http://localhost:8080/actuator/health
curl http://localhost:8080/actuator/metrics
curl http://localhost:8080/actuator/prometheus   # raw Prometheus metrics

# Register → Login → Get Profile
TOKEN=$(curl -s -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"priyank@ecommerce.com","password":"Password123"}' \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['data']['accessToken'])")

curl http://localhost:8080/api/v1/auth/me \
  -H "Authorization: Bearer $TOKEN"
